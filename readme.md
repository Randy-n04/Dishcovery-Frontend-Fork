### Overview
---
DishCovery is a mobile app for Android, based on the concept of "Swap". The 
purpose of this app is to allow two different users to share their
respective knowledge about a certain recipe to each other, thus being able to
"swap" their recipes to each other

Developed in Kotlin, DishCovery uses Jetpack Compose on a CLEAN architecture.

### Project Objectives:
---
- Learn how to create visual views for Android Apps.
- Apply programming principles to guarantee an organized, maintainable and scalable code.
- Use of complementary tools related to mobile development and AI.

### Main Features:
---
- Users can swap recipes with another person on the platform, allowing them to learn about a new recipe and teach the other about something they want.
- Integration of an AI API in the swap, who decides based on the users requested recipes.
- Admin users can access their own page where they can check on the page condition. 

### Tech Stack:
---
- Kotlin
- Jetpack Compose UI
- Gradle build system

### Getting started:
---
1. Clone the repository
2. Open Android Studio
3. Build Gradle and run the application on a device
